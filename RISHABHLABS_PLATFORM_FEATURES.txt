1. EXECUTIVE OVERVIEW & PHILOSOPHY
--------------------------------------------------------------------------------
RishabhLabs is a high-performance developer execution and proof-of-work 
ecosystem. Rather than passive video-watching, the platform is engineered 
around active execution: daily missions, living adaptive roadmaps, browser-based
Monaco sandboxes with progressive AI hints, automated multi-platform hackathon 
aggregation, 1:1 industry mentorship, campus enterprise analytics, and 
tamper-proof developer portfolios.

The platform natively supports 4 distinct user roles:
  - Students / Developers (Daily learning, practice, hackathons, portfolio)
  - Industry Mentors (Office hours, 1:1 video review, profile management)
  - College / Campus Admins (Department analytics, cohort velocity, placement KPIs)
  - Super Admins (Full platform governance, questions, roadmaps, pricing)

14. TECHNICAL STACK & BACKEND SERVICES SUMMARY
================================================================================
A. Frontend Stack:
   - React 18 with TypeScript and Vite.
   - Tailwind CSS for modern responsive styling.
   - Monaco Editor for code practice.
   - Canvas-Confetti & Lucide React for rich micro-interactions and icons.

B. Backend Stack:
   - Node.js & Express with TypeScript.
   - Dual Database Architecture:
     * MongoDB (Mongoose): High-speed storage for questions, missions, roadmaps, and profiles.
     * Supabase (PostgreSQL): Real-time change streams, mentorship sessions, and campus cohorts.
   - Google Gemini API: Fast flash models powering adaptive roadmaps, mission generation,
     and progressive hints.
   - Isolated Code Execution Engine: Child process sandboxing with timeout and memory enforcement.
   - Playwright Scrapers: Headless multi-platform scrapers for Devpost, Unstop, and Luma.
   - Resend / Nodemailer: Transactional emails, session invites, and OTP verification.
